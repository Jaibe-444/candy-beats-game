# 🍬 Candy Beats - Pattern Memory Game

A simple, colorful, and accessible single-player pattern-matching memory game built using vanilla HTML5, CSS3, and JavaScript. Inspired by classic handheld memory games like *Simon*, this project challenges players to remember and repeat increasingly long sequences of visual lights and musical tones.

## ✨ Key Features
* **Multiple Difficulty Levels:** Easy (4 candies, slower playback), Medium (4 candies, fast playback), and Hard (6 candies, dynamic speed).
* **Web Audio API:** Generates real-time, pleasant musical notes in frequency without external audio file dependencies.
* **Eye-Friendly Aesthetic:** High-contrast, soft pastel colors with smooth glow states designed for visual comfort.
* **Score System:** Features real-time score updates and saves your personal best score in your browser's local storage.

## 🚀 How to Run Locally
1. Clone or download this repository to your machine.
2. Open `index.html` directly in any web browser, or use VS Code's "Live Server" extension.
3. Select a difficulty level and click **Start Game**!

## 🛠️ Tech Stack
* **HTML5:** Semantic document markup.
* **CSS3:** Custom properties (CSS variables), CSS Grid layout, flexbox, and CSS keyframe animations.
* **JavaScript (ES6+):** Game engine state loop, async timers, DOM manipulation, and Web Audio API synthesizer.
